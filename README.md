# Davi Teixeira — Portfólio

Landing page de portfólio pessoal voltada para **Dados, Business Intelligence (BI), Bancos de Dados, ETL, Dashboards e Analytics**.

## Stack
- HTML5 e CSS3 puros (Grid, Flexbox, `clamp()`, media queries) — sem frameworks nem build tools
- Fonte [Exo 2](https://fonts.google.com/specimen/Exo+2) (Google Fonts)
- Layout responsivo (breakpoint em 745px)

## Estrutura
```text
index.html          # Página única (Sobre, Contato, Projetos)
css/
  index.css         # Variáveis, reset, estilos globais e imports
  header.css        # Cabeçalho e menu
  sec1.css          # Apresentação e skills
  sec2.css          # Foto, citação e contatos
  projetos.css      # Seção e cards de projetos
  mq-745.css        # Responsividade mobile
js/carrossel.js     # Setas do carrossel de projetos
files/curriculo/    # Currículo em PDF
imgs/               # Logo, foto, favicon e ícones SVG
state.md            # Estado atual do projeto
```

## Uso
Abra o `index.html` no navegador.
